# L796 ALT-PN Single-Cell Model

This folder contains the L796 ALT-PN reconstructed morphology and modelling workflow used for passive fitting, active conductance grid search, current-step validation, and final Step 5 active tuning.

## Model status

The current final model is the Step 5 tuned active model. Passive fitting is complete. Active conductances are feature-tuned because exact L796 conductance densities were not available.

## Main workflow

1. Morphology inspection
2. Passive leak fitting
3. Active conductance grid search
4. Current-sweep validation
5. Final tuning
6. F-I curve and firing-frequency analysis

## Final interpretation

The final model shows delayed repetitive / tonic-like firing. It should be treated as a morphology-based, passive-fitted, feature-tuned active model, not an exact biological reconstruction of L796.
