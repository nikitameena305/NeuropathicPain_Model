# Archive

This archive contains scientifically useful material that is not part of the three current production-cell packages.

- `L796/`: historical L796 audits and a preserved one-line 1000 ms script variant.
- `other_exploratory_models/GRP_14-1-15-A-A2sep_and_candidates/`: separate mouse GRP excitatory-interneuron morphology search; never presented as L292-E1.
- `other_exploratory_models/early_project_work/`: early DRG/SDH ball-cell, ModelDB, morphology-screening, submission, and network/pain-condition studies.

Archived work remains scientifically useful for provenance and model-development history. Current parameter sets and validation entry points live under `cells/`.
