# Early project work

This directory preserves the repository's pre-consolidation DRG/SDH exploration, ModelDB extraction, NeuroMorpho screening, early ball-cell demonstrations, and network/pain-condition projects 1, 3, 4, and 5.

These artifacts were archived because they do not belong inside any one of the three current cell packages. They remain scientifically useful for provenance and for understanding earlier circuit hypotheses. The byte-identical `submission_week1/` package was removed after every file was matched to a retained canonical source artifact.

The former `modeldb/2018004` entry was a broken Git link: its referenced object was unavailable and the repository had no `.gitmodules` entry. The original pointer is recorded in `modeldb/2018004_GITLINK_NOTE.md`; the surviving ModelDB evidence remains in the archived logs and deliverables.
