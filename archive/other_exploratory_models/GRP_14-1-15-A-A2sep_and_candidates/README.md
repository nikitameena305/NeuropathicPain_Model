# Separate GRP morphology candidates

This directory contains a mouse GRP-expressing excitatory-interneuron morphology search, including `14-1-15-A-A2sep` and two alternatives. It is retained as a separate reference only.

It is **not** L292-E1-LCN, is not part of the L292 production scaffold, and must not be used as evidence for L292-E1 identity or validation.
